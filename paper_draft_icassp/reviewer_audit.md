# 严格自审与补充实验优先级

日期：2026-09-06。审阅对象为本目录修订后的英文稿，不是原始公开 Fold 0 版本。以下是内部审稿判断，不是实际会议评审意见。本文全文和图表已完成；本次没有启动新增训练或实验。

## 总体判断

目前最有价值的内容是 **有效同源 checkpoint 对上的冻结头回退实验**：低分四分之一与高分四分之一的影响相差很大，且 D0 表明这一删除排序不保证各预算下的最佳保留性能。它能构成一篇问题明确的分析型初稿，但距离有竞争力的 ICASSP 投稿，主要差距在实验证据和知识增量，而不在英文流畅程度。

以严格审稿标准，当前最可能导致拒稿的组合是：**标准 Taylor saliency 应用于最后层差分的新颖性有限，加上关键 scale/readout 控制与训练重复不足**。原稿公开 Fold 0 的来源问题若未移除会直接损害技术可信度；该项已在本稿修复。不能因为修复了可信度问题，就把剩余的证据深度视为已经足够。

## 1. 新颖性：究竟新增了什么知识？

**可能的评语。** 表示差分已有 Mind the Shift；activation × gradient 已有 Taylor pruning；按分数删除更影响输出也符合 saliency 的设计。当前到底揭示了哪一项超出这些已有认识的新现象？

**现稿可以回答。** 先前 fusion 训练新头，本稿保持原适配头；同一模型的 Full/NoShift/retention/deletion 具有明确解释。D0 在不同预算和缩放控制下的反例提供了一个比“排序有效”更具体的发现：组级删除影响与有限预算保留质量不一致。

**仍不能回答。** 这种不一致由什么因素产生；它是否稳定出现在相同训练条件下；是否比 head-column norm 等简单最终头统计量揭示更多。不能把“提出 DADS”本身当作已证明的理论或普遍技术创新。

**已做修改。** 移除最小支持集/最优性暗示，引用既有 saliency，贡献围绕有限的功能依赖结果与反例表述。

## 2. 技术可信度：是否真的是 fine-tuning shift？

**已修复。** 公开 Fold 0 两端架构不匹配，主文全部撤下；W1/W2/D0 通过本地初始化记录、两端配置、缓存来源和核心结果字段确认。校准公式修正为逐句归一化 CTC、逐帧取绝对值后平均，避免与共享 gate 的精确导数混淆。

**剩余问题。** W1/W2 缺直接模型输出与缓存输出逐句吻合的现有报告；训练 dev WER 与缓存 Full WER 不完全相同。实际 dev/test 没有超过 10 s 的音频，不能把差异简单归因于裁剪。D0 已有 direct/cache 一致记录，但训练汇总指标仍与该路径略有差异。

**投稿要求。** 应明确唯一评估路径，保留逐句输出和归一化版本，解释历史差异。即使缓存代数重构误差很小，也不能据此替代实际 head/processor/checkpoint 的直接验证。

## 3. 实验充分性：最强效果与最缺的控制

最强对照是 W1/W2 同等规模高低分删除：相对 Full 的 WER 变化为高分 +7.10/+9.86 pp、低分 +0.22/+0.08 pp。这个差异无需诉诸原稿超过 100% 的异常端点就存在。

但以下内容仍使分析深度不足：

- 只在 D0 上有 gradient、random、random+rescale 完整比较；不能假设 W1/W2 的 DADS 优势在加入这些控制后仍成立。
- D0 的 75% 改善只有 −0.43 pp，尚无有效配对的不确定性；50% 的负向控制必须保留。
- 一个模型一个训练 seed，不能将跨 fold 或随机 mask SD 当成适配稳定性。
- 两种模型同时改变预训练体系、适配损失、batch、schedule、fold 和训练预算；不足以比较 wav2vec 与 data2vec 的机制差异。
- calibration 来自训练内数据；跨校准子集的稳定性与跨训练/说话人的泛化是不同问题。

## 4. 解释边界：可排除与不可排除的替代解释

| 替代解释 | 当前证据怎样约束它 | 还需要什么 |
|---|---|---|
| “只是选了位移大的坐标” | 同预算 DADS50 优于 magnitude50，三对模型都成立 | 与 gradient-only、head-column norm、匹配尺度的 magnitude 比较 |
| “随机删除只是缩小了位移” | D0 同随机 mask 的 rescale 大幅改善 50% WER | 对所有排序应用同样的 scale 规则，在 dev 锁定规则后比较 |
| “高分只反映最终头权重” | 固定头是本稿对象，当前实验并未排除此解释 | 最终头范数/有效 logit 位移基线；head 与 encoder 交叉比较 |
| “适配提取了特定音素/口音信息” | 没有相应音素或口音条件分析 | 预先指定 linguistic groups，检验误差类型与坐标干预的联系 |
| “是任意坐标基下的稀疏信息” | 只在 native basis 测量 | 输出不变的正交旋转对照；避免把坐标当独立语义因素 |
| “低分变化完全无用” | 回退一个组后 WER 小变，只说明该测量下的作用小 | 多组联合干预、交互与不同读出；不能由一组结果推出单坐标普遍无用 |
| “是纯粹从零增加了有用特征” | 移除 delta 后仍保留源表示，所有输入仍为 1024 维 | 不应表述为保留的 delta 单独足够识别 |

最终线性头还带来一个基本约束：32-symbol logits 是 1024-dimensional hidden state 的线性投影，CTC 的监督梯度经过这个头回传。因此“高分坐标更影响固定头”可能在很大程度上反映头的投影几何。它依然是可测的功能依赖，但不能自动等价于完整 encoder 的适配机制。这是需要优先区分的解释，不是本稿已经测得的新实验结果。

## 5. 按重要性排序的补充工作

下列均为 **待做建议**。本次只整理已有输出，没有执行它们。预算写的是工作类型，不捏造 GPU 小时数。

| 优先级 | 补充项目与预先定义的比较 | 它将验证/修复的主张 | 是否需训练 |
|---|---|---|---|
| P0 | 固化 W1/W2/D0 的 checkpoint/processor/hash，补 W1/W2 逐句 direct-vs-cache Full 对比；统一训练记录与缓存评估指标 | 数值确实属于指定适配模型与评估路径，排除实现差异 | 否，验证性推理 |
| P1 | W1/W2 补齐 D0 已有的 Gradient、Random、Random+Rescale，在 25/50/75% 同预算评估，并至少保持相同 mask seeds | DADS 相比完整控制的实际范围，而非仅 magnitude 优势 | 否，可利用已有缓存和头 |
| P1 | 对 DADS/Magnitude/Gradient/Random 使用同一 scale 规则；加统一 `E0 + alpha*delta` 的尺度对照，alpha 仅在 dev 选择；同时比较 `d/K` 与预先定义的范数匹配 | 区分坐标组成、尺度与偏离完整适配点的作用；检查 D0 反例原因 | 否，缓存干预 |
| P1 | 在有效配对上导出相同 utterances 的 edits/reference counts，做配对差值不确定性；报告 speaker-level 分解，明确仅六位 test speakers 的局限 | 75% “接近 Full”和 D0 小幅改善是否稳定 | 否，现有逐句预测若齐全可只做统计；不能复用公开 Fold 0 CI |
| P1 | 增加同一 split/recipe 的独立适配 seeds，保留所有运行，再比较高低分删除差和关键 retention 对照 | 主要发现是否跨训练随机性成立 | 是，需之后另行安排 |
| P2 | 加简单 readout 基线：head-column norm、聚合绝对 logit displacement；对相同 encoder/head 配对分析其与 DADS 的关系 | Taylor 分数是否提供超出最终线性头几何的新知识 | 不一定；核心统计/缓存干预无需训练 |
| P2 | 同一 source、split、batch/schedule 与预算下做 CTC-only vs CTC+SupCon；已有不同模型结果不替代此对照 | 观察来自一般 ASR 适配还是特定 regularization recipe | 是 |
| P2 | 按预先确定的规则留出独立 calibration speakers/utterances，再与训练内校准比较；确认与 encoder 训练的独立性 | 排序的泛化与训练内标注重用的影响 | 严格独立方案可能需重训；不能只重命名已有子集 |
| P2 | 对 E0/Eft 施加同一正交旋转并相应变换线性头，使 Full logits 保持不变，再重新排序/干预 | “不均匀”在多大程度上依赖 native coordinate basis | 否，数值/缓存干预 |
| P3 | 有明确适配机制假设后，做音素混淆、说话人/L1 和层次分析；控制头映射和 frame alignment | 将目前功能依赖提升为具体可证伪的声学解释 | 依方案而定 |
| P3 | 若最终确实要覆盖儿童语音，再增加独立 child-ASR 数据与来源清楚的成对模型 | accented speech 结论是否转移到儿童语音 | 通常需要；当前标题和贡献不依赖它 |

公开 Fold 0 的恢复不是当前稿的必选项。如果需要恢复，先找出并验证真正的初始化，再重做相关特征、排名和评估；仅修改 config 字段或把两个相减后能重构当作检查，不能修复 lineage。

## 6. 一个有竞争力版本应达到的最小证据目标

先完成 P0，保证可复现对象可靠。随后优先让 **相同模型上的完整 scale/readout 控制** 和 **有效配对的不确定性/训练重复** 回答两个问题：高低分删除差是否稳定，以及这种差异比一般最终头敏感性多解释了什么。若这些控制支持更具体的现象，再围绕该现象重写贡献；若它们削弱 DADS，保留反例并把论文转向解释排序为何失败，也比扩大未经验证的成功主张更有价值。

不需要为了“分析论文”堆更多相关性热图，也不需要为标题加入儿童语音而无目标地扩展数据集。补充工作应能改变对核心解释的判断。
